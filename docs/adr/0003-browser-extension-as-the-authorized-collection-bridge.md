# Chrome 扩展作为已授权采集桥接

已接受。服务端不读取、不保存或传输用户 Chrome Cookie；已绑定的 Chrome 扩展在用户授权的京东页面中运行固定采集脚本，并通过扩展主动建立的认证 WebSocket 接收采集命令和回传结构化结果。

## Considered Options

- 服务端直接抓取商品页：无法合法复用用户本地登录态，且会把反爬规避变成服务端职责。
- 本地桌面应用：分发与证书负担高，不符合 Web 服务目标。

## Consequences

扩展第一版从系统网页下载后由用户手动加载；Chrome Web Store 发布和企业策略安装留作后续事项。采集脚本只读取允许的商品页面内容和媒体，绝不导出登录态、订单或 Cookie。
