# 商品视频生产系统

本上下文描述一个由内部成员使用的商品采集与视频生产系统。它以用户已授权的浏览器页面为采集边界，以可审计的项目和产物为业务核心。

## 语言

### 生产对象

**项目（Project）**：
用户创建的一次完整商品视频制作需求，最终交付一个合集 MP4 和一张独立封面图。
_Avoid_: 任务、订单、视频

**采集会话（Capture Session）**：
一个项目委派给某个已绑定 Chrome 扩展的单次浏览器采集过程。
_Avoid_: 采集任务、浏览器任务

**商品快照（Product Snapshot）**：
某次采集会话从商品页面取得的不可变事实记录，包含来源链接、采集时间和可售 SKU 数据。
_Avoid_: 商品缓存、实时商品

**SKU**：
商品快照中一个可售的具体款式及其关联规格、图片和价格事实。
_Avoid_: 款式、变体（除非指外部页面原文）

**候选方案（Candidate Plan）**：
LLM 针对同一项目独立生成的一套完整卡片计划，供用户选择和编辑。
_Avoid_: 口播稿、模板

**卡片（Card）**：
候选方案中可独立播放的最小视听单元；绑定一个 SKU、已采集字段、视觉内容和一段口播。
_Avoid_: 页面、幻灯片

### 执行对象

**作业（Job）**：
后台可领取、可审计的最小执行单元，例如下载素材、生成候选方案、合成音频或渲染视频。
_Avoid_: 项目、任务

**执行通道（Execution Lane）**：
由同类 Worker 与并发限制共同定义的一组作业队列，例如采集、LLM、TTS、渲染。
_Avoid_: 全局队列

**产物（Artifact）**：
持久化保存的原始图片、音频、封面、MP4 或其元数据。
_Avoid_: 缓存、临时文件
